# TalentMatch: AI-Based Resume Screening & ATS-Optimised Resume Generation

> An AI web app that screens resumes against job descriptions using **keyword matching plus BERT semantic similarity**, and helps job seekers improve their resumes with **Gemini-powered feedback** and an **ATS-friendly resume builder**.

## The Problem

Traditional Applicant Tracking Systems (ATS) rely on exact keyword matching, so strong candidates are filtered out for wording differences. Job seekers, meanwhile, rarely learn why their resume didn't make it.

TalentMatch closes this gap with a **two-sided feedback loop**:
- **Recruiters** get fairer, explainable candidate ranking.
- **Job seekers** get a match score, missing skills, ATS feedback and AI-written improvement tips.

## Features

### 👩‍💼 Recruiter Dashboard
- Create job postings and upload multiple resumes (**PDF / DOCX**) for ranking
- Ranked candidate list with match score, matched skills and missing skills
- **AI candidate summaries** generated by Gemini
- **Adjustable scoring weights** per job (keyword vs. semantic), with automatic re-scoring
- Job metrics, activity feed, and edit / delete for jobs and candidates

### 🧑‍🎓 Job Seeker
- Upload a resume and paste a job description to get a **match score**
- **Skill gap analysis:** matched vs. missing skills
- **ATS structure check:** flags sections and formatting that hurt ATS parsing
- **Gemini-powered feedback:** structured, context-specific improvement tips

### 📝 ATS Resume Builder
- Guided form to build an ATS-friendly resume
- **AI-generated bullet points** and **professional summary**
- Live preview, scoring against a target role, and **DOCX download**

## How It Works

```
Resume (PDF / DOCX) ──► Text extraction (pdfplumber, python-docx)
                                   │
Job description ──► Skill extraction (regex skill patterns + aliases + spaCy NER)
                                   │
              ┌────────────────────┴────────────────────┐
              ▼                                         ▼
   Keyword score                              Semantic score
   % of required skills found          BERT embeddings (all-MiniLM-L6-v2)
   (whole-term matching)               over the whole document
                                       └─ TF-IDF fallback
              └────────────────────┬────────────────────┘
                                   ▼
        Match score = w × keyword + (1 − w) × semantic   (default w = 0.6)
                                   │
                                   ▼
          Gemini 2.5 Flash ──► candidate summaries & improvement tips
                                   │
                                   ▼
                       SQLite (jobs, scores, activity)
```

1. **Parsing:** resume text is extracted with `pdfplumber` (PDF) and `python-docx` (DOCX).
2. **Skill extraction:** required skills are pulled from the job description with a curated library of regex skill patterns (with aliases, e.g. *"ML" → "machine learning"*), plus spaCy named-entity recognition.
3. **Keyword score:** the percentage of required skills found in the resume, using whole-term matching so `java` doesn't match `javascript` and `c` doesn't match `c++`.
4. **Semantic score:** `all-MiniLM-L6-v2` only reads ~256 word pieces, so each document is split into **overlapping 150-word windows**. The windows are embedded and mean-pooled so the **whole resume** is compared, not just the first paragraph. Similarity is measured with cosine similarity. TF-IDF is used as a fallback.
5. **Combined score:** a weighted blend of the two scores. Recruiters can tune the weight per job.
6. **Generative AI:** Gemini 2.5 Flash writes candidate summaries, job seeker feedback, resume bullet points and summaries.

## Getting Started

### Prerequisites
- Python 3.11
- A Google Gemini API key

### Installation

```bash
git clone https://github.com/sherinaaleeyah/resume-ai-pwa.git
cd resume-ai-pwa/resume-ai-system
python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install -r requirements.txt

# Optional: spaCy for extra skill detection
pip install spacy
python -m spacy download en_core_web_sm
```

### Configuration

Create a `.env` file inside `resume-ai-system/`:

```
GOOGLE_API_KEY=your_gemini_api_key_here
```

### Run

```bash
python app.py
```

Open `http://127.0.0.1:5000` in your browser. The SQLite database (`hiring_dashboard.db`) and `uploads/` folder are created automatically.
